## What the BOM Reveals (FRAMECAD Structure v11.1.12.0 output)
Document = "Manufacturing Summary" auto-generated by FRAMECAD Structure software. A human detailer (name on doc: PAVAN) modeled the project from Larry's plan PDFs — **that manual detailing pass is the 5-day lead time and the cost we can remove.**

### Structure
- Organized by **tabs = assembly groups**: `Panel.1` (wall panels) and `Truss.1` (roof trusses)
- Columns: Material | Part Number | Qty | Weight (lbs)
- Members listed as **aggregate total lineal feet per profile** (not per-piece) — e.g. `362S162-43-50 … 5325'-11 1/2" … 6370.4 lbs`
- Connections/fasteners as counts with FRAMECAD part numbers
- Job Summary section = union of all tabs + total weight

### Member/profile conventions
- **SSMA-style designations with ksi suffix**: `362S162-43-50` = 3-5/8" web stud, 1-5/8" flange, 43 mil (18ga), 50 ksi. `600S162-43-50` = 6" stud. Trusses use lighter `362S162-33-50` (33 mil / 20ga).
- **Lintels in FRAMECAD metric profiles**: `600x125x33`, `600x125x43`, `850x125x54` (web×flange mm × mil)
- **Hot-rolled mixed in**: `S7x15.3` American Standard beam, 121'-8", 1,862 lbs — they drop hot-rolled sections where CFS can't span. Blueprint must flag long-span conditions rather than force CFS.
- **FRAMECAD proprietary connectors**: Apex/Heel Plates (AHCP-A2, qty 92), Fix Plates (FP-A2, qty 184), screws 10g-16mm Flathead (3,128) + 10g-19mm XDrive (21,806)

### Allen job composition
- Walls (Panel.1): ~15.2k lbs CFS + 1.9k lbs S-beam; two stud families (362 + 600 series, both 43 mil)
- Trusses (Truss.1): 18.4k lbs, single profile 362S162-33-50 — trusses are ~52% of total steel weight
- Screw counts are enormous (25k+) — connection count estimation matters for real quotes

## Implications for Blueprint `kit_package`
1. **Target output = a "Manufacturing Summary"-equivalent**: members aggregated by profile per assembly tab (Walls / Trusses), total LF + weight per profile, grand total lbs. Matching their format = zero-friction intake for their estimator.
2. **Use SSMA designations + mil gauges** — the industry lingua franca. Map Revit wall types/framing to a profile selection table (AISI S230 prescriptive tables pick the profile from span/height/load).
3. **Weight is the money number** — pricing is effectively $/lb. Blueprint computing total lbs from the model = instant ballpark pricing capability (35,510 lbs × their rate) BEFORE any fabricator is even contacted. We can quote customers same-day.
4. **Truss handling**: output truss count, span, pitch, spacing + profile assumption; let fabricator/Juston finalize web design. Trusses ≈ half the steel weight, so even approximate truss weight gets ballparks close.
5. **Flag hot-rolled needs**: detect spans/point loads beyond CFS prescriptive limits → callout for S-beam/HSS insert.
6. **Fastener/plate counts**: v1 can estimate from member counts via ratios derived from this BOM (e.g. screws ≈ 0.7/lb of steel here); refine later.
7. **What ASF never sent**: panel drawings, the FRAMECAD model, engineering — they keep those. Confirms the value gap: if Blueprint + Juston produce layout + schedule + stamps, ASF's remaining role is rolling steel → toll pricing conversation.
